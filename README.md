# ovemo-checksums — отпечатъците на файловете на плъгините и темите на Ovemo

Публично хранилище. Тук няма код: само имената на файловете и техните отпечатъци (SHA-256), по версия.
Решено 10.10.2026 (`ПЛАНОВЕ-Ovemo-Security.md`, решение 5); направено 25.10.2026, 14:25 ч. (собственикът: „2. а“).

Пазачът на файловете в Ovemo Security (`Ovemo_Security_Files`) чете оттук всяка нощ без парола и сверява файловете
на сайта: променен файл или файл, който го няма тук, е сигнал от пазача.

## Устройство
- `plugins/<папка>/<версия>.json` и `themes/<папка>/<версия>.json`:
  `{"version": "...", "files": {"път/до/файл.php": "sha256", ...}}`.
- Файловете се пишат сами: куката `~/.claude/hooks/package-sync.sh` след всеки commit на плъгин или тема слага
  същите файлове, които отиват в `ovemo-package`, и ги праща тук. На ръка тук не се пише.
